1 Purpose and statistical scope

This document complements the modelling reports with a broad but statistically valid analysis suite. It does not apply every named test indiscriminately: invalid assumptions, duplicate hypothesis tests and significance fishing weaken a study. The analyses below are selected because they match the variable types, sample design and decision objective.

The scope includes data quality, descriptive statistics, uncertainty intervals, numeric and categorical group comparisons, effect sizes, correlation/multicollinearity, adjusted logistic associations, temporal analysis, calibration, CRC policy risk, bootstrap finalist comparison and subgroup monitoring.

4 3. Returned versus retained: numeric-variable inference

Welch tests compare group means without assuming equal variances. Mann–Whitney tests compare rank distributions and are robust to skew/outliers. Standardised mean difference supplies practical effect magnitude. For computationally stable reporting, each group is deterministically capped at 50,000 observations; the full descriptive analysis remains unchanged.

# 3. Returned versus retained: numeric-variable inference

Welch tests compare group means without assuming equal variances. Mann–Whitney tests compare rank distributions and are robust to skew/outliers. Standardised mean difference supplies practical effect magnitude. For computationally stable reporting, each group is deterministically capped at 50,000 observations; the full descriptive analysis remains unchanged.

```{r numeric-tests}
numeric_tests <- rbindlist(lapply(numeric_vars, function(v) {
  a <- sample_n(analysis_dt[isReturned == 1 & is.finite(get(v)), get(v)])
  b <- sample_n(analysis_dt[isReturned == 0 & is.finite(get(v)), get(v)])
  if (length(a) < 2 || length(b) < 2) return(data.table(variable = v))
  tt <- t.test(a, b)
  wt <- wilcox.test(a, b, exact = FALSE)
  data.table(
    variable = v, returned_mean = mean(a), retained_mean = mean(b),
    mean_difference = mean(a) - mean(b), t_p_value = tt$p.value,
    t_ci_low = tt$conf.int[1], t_ci_high = tt$conf.int[2],
    wilcoxon_p_value = wt$p.value, standardized_mean_difference = smd(a, b)
  )
}), fill = TRUE)
numeric_tests[, t_p_bh := p.adjust(t_p_value, method = "BH")]
numeric_tests[, wilcoxon_p_bh := p.adjust(wilcoxon_p_value, method = "BH")]
numeric_tests[, practical_effect := fifelse(abs(standardized_mean_difference) < .10, "negligible",
  fifelse(abs(standardized_mean_difference) < .30, "small",
    fifelse(abs(standardized_mean_difference) < .50, "moderate", "large")))]
fwrite(numeric_tests, file.path(TABLE_DIR, "stat_06_numeric_outcome_tests.csv"))
show_table(numeric_tests[order(-abs(standardized_mean_difference))],
           "Numeric group comparisons, effect sizes and BH-adjusted p-values")
```

**Inference rule:** With a data set this large, a very small p-value can accompany a negligible difference. Practical conclusions should prioritise effect size and confidence intervals.
